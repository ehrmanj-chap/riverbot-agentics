# Riverbot Agentics

Public website for **Riverbot Agentics**, an applied agentic AI consulting practice.

The site is intentionally static and dependency-free so it can be hosted directly with GitHub Pages.

## Publish with GitHub Pages

In this repository:

1. Open **Settings** → **Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**.
4. Save.

The site should publish at:

`https://ehrmanj-chap.github.io/riverbot-agentics/`

## Files

- `index.html` — site content and structure
- `styles.css` — responsive styling
